# 番茄钟 PomodoroTimer

一个 Electron 桌面番茄钟。**它的核心特色是「到点提醒」**：时间一到，屏幕顶部会弹出一个不会自己退回去的置顶弹窗，同时屏幕四周亮起向内的淡蓝色呼吸光效。

- 需求与进度全程维护在 **`计划.md`**
- 默认节奏：**40 分钟专注 / 5 分钟短休 / 每 4 轮 10 分钟长休**（全部可在设置里改）

## 快速开始

```powershell
cd E:\dsh\test1
pnpm install      # 首次需要，会下载 Electron 二进制
pnpm start        # 启动番茄钟
```

> 关闭主窗口 = **退出程序**；点标题栏的 `—` = **收进托盘**，计时继续跑。

---

## 到点之后会发生什么

1. 屏幕**四周亮起**向内的淡蓝色光效，呼吸脉动；这层光**鼠标点击完全穿透**，不会挡你操作任何软件。
2. 屏幕**顶部居中**弹出一张卡片，**置顶显示、不抢键盘焦点、不会自动消失**，它盖得住全屏应用。
3. 同时响一声合成的柔和钟声。
4. 你有两个出口：

| 操作 | 结果 |
| --- | --- |
| 点「**5 分钟后再提醒**」按钮 | 弹窗和光效收起，**5 分钟后重新弹出并再次响铃**（可以无限次延后） |
| 按全局快捷键 **`Ctrl + Alt + P`** | 同上。任何软件里都生效，不用切回番茄钟 |
| 把**滑块拖到最右端**松手 | **进入下一轮循环**：该休息就休息，该专注就专注 |
| 滑块只拖一半就松手 | 弹回原位，什么都不会发生（防误触） |

> 休息时长如果被设成 `0` 分钟，就**跳过休息**，「进入下一轮」会直接开始下一次专注。

## 界面

- **主窗口**：环形进度 + 大号倒计时 + 开始/暂停、跳过、重置；点右上角齿轮进设置。
- **小浮窗**：常驻屏幕**正上方居中**，**只显示时间**。默认开启，且默认**完全点击穿透**（不挡鼠标）；在设置里勾上「可以拖动」就能把它拖走。
- **托盘**：最小化后计时照跑，托盘右键可直接开始/暂停、跳过、重置、打开设置、退出。

## 设置项

| 分组 | 可以改什么 |
| --- | --- |
| 计时 | 专注时长、短休时长、长休时长（**都能精确到秒**，用「分 + 秒」两个框填）、每几轮进长休。**改动对正在跑的这一轮立即生效**（剩余时间按新时长重算） |
| 提醒 | 延后时长（可精确到秒）、全局快捷键（点按钮后直接按组合键录制）、提示音开关与音量、试听 |
| 四周光效 | 颜色（默认淡蓝 `#4fc3f7`）、强度、闪光时长。**到点只闪一次，闪完保持常亮** |
| 小浮窗 | 是否显示、是否可以拖动。背景完全透明，只留时间 |
| 其它 | 开机自启、恢复默认设置 |

## 几个说明

- **休眠/睡眠/锁屏会自动暂停**，唤醒后从暂停处接着跑 —— 不计入你离开电脑的时间。
- **开机自启默认开启**（你选的那一项）。它会在注册表 `HKCU\...\Run` 写入一条启动项，启动时带 `--hidden` 参数直接静默进托盘。不想要就在设置里关掉。
- **配置存放位置**：`%APPDATA%\pomodoro-timer\config.json`
- 程序同一时间只允许开一个实例，重复启动会聚焦已有窗口。

## 开发脚本

| 命令 | 作用 |
| --- | --- |
| `pnpm start` | 启动应用 |
| `node scripts/test-timer.js` | 计时状态机单元测试（纯 Node，29 项） |
| `$env:POMODORO_E2E='1'; pnpm start` | 端到端自检 62 项：真跑提醒链路、用真实输入管线操作滑块与按钮、断言四个窗口的 DOM、抓桌面截图做像素差分，截图存到 `screenshots/` |
| `node scripts/make-icons.js` | 重新生成 `assets/icon.png` 与 `assets/tray.png`（纯代码绘制的番茄） |

按 `计划.md` 第 7 节的约定：**每做一部分就验证，只要有一条 FAIL 就不算做完**；关键改动还会派独立子代理做对抗性审查。

## 目录结构

```
src/
├─ main/
│  ├─ main.js        主进程入口，把各模块串起来
│  ├─ timer.js       计时状态机（跑在主进程，窗口隐藏也不受影响）
│  ├─ windows.js     主窗口 / 提醒弹窗 / 光效层 / 小浮窗
│  ├─ tray.js        托盘与菜单
│  ├─ shortcuts.js   全局快捷键
│  ├─ store.js       配置持久化
│  └─ e2e.js         端到端自检（仅 POMODORO_E2E=1 时加载）
├─ preload/preload.js
└─ renderer/         四个窗口的界面（原生 HTML/CSS/JS，无打包器）
```
